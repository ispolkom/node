# Реестр безопасности YANDI (SECURITY_STATUS)

Единый перечень находок независимых проверок с постоянными номерами. Источники: **Sol** — Codex (модель gpt-6.1-sol), **Sonnet** — Claude, **GPT** — внешний аудит 2026-10-09.
Старые отчёты не переписываются и остаются историческими свидетельствами; здесь записано, что реально устранено и чем это подтверждено. Реестр собран скриптом `tools/security_registry.py`; статусы заданы по истории git, отсутствующие сведения помечены прямо.

## Статусы

`Обнаружено` → `Подтверждено/воспроизведено` → `Исправлено в коде` → `Проверено автотестами` → `Проверено на устройствах` → `Закрыто`. Отдельно: `Не подтверждено`, `Отклонено с обоснованием`, `Риск принят`, `Открыто` (не смешиваются с успешным исправлением).
**«Закрыто» не присвоено ни одной записи:** физических испытаний в сети из нескольких узлов и на нескольких устройствах по этим исправлениям пока не проводилось.
