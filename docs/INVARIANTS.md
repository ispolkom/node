# Инварианты: то, что не меняется

Короткий список обещаний проекта. Они защищают замысел от «улучшений», которые на деле его портят. Правило: **изменить инвариант можно только отдельным решением владельца**, не по ходу работы над функцией. Каждый инвариант охраняется тестом; если теста ещё нет, это написано прямо («ждёт», фаза плана).

Тест `tests/invariants.rs` проверяет сам этот документ: каждая ссылка на тест вида `файл::имя` должна существовать, а у каждого инварианта должна быть либо хотя бы одна такая ссылка, либо отметка «ждёт» с фазой. Документ не может разойтись с тестами.
