# YANDI

**Децентрализованная одноранговая сеть для общения и доступа в интернет через собственные узлы.** Зашифрованная переписка, передача файлов, аудио- и видеозвонки, HTTP/SOCKS5 и многопереходная маршрутизация. Без обязательного центрального сервера обмена сообщениями и без учётных записей. Границы шифрования зависят от сценария связи; см. [описание конфиденциальности](docs/PRIVACY.md).

[Скачать](https://yandi.su/ru/network/) · [Сайт](https://yandi.su/ru/) · [Полный README (English)](README.md)

## Установка узла из консоли

```bash
sudo apt install ./yandi-node_*.deb
yandi setup                       # язык, пароль, сид-фраза (12/24 слова), закрытая среда — от обычного пользователя
yandi admin pairing owner --host ВАШ_ВНЕШНИЙ_АДРЕС     # код и QR для телефона
```

**Запишите сид-фразу на бумагу:** она показывается один раз. Служба systemd, порты (`8444/tcp`, `9000/udp`, `10000/udp`) и сетевые буферы: пошаговая инструкция на страницах [Debian](https://yandi.su/ru/network/downloads/debian/) и [Ubuntu](https://yandi.su/ru/network/downloads/ubuntu/) и в [`DEPLOYMENT.md`](DEPLOYMENT.md). `apt remove yandi-node` сохраняет профиль; `apt purge yandi-node` запрашивает его удаление. Физическое стирание на SSD и удаление резервных копий не гарантируются.

## Что есть

- Чаты, файлы, группы и звонки через свой узел. Спаренные телефоны используют E4 между устройствами; чат между компьютерными узлами — YSE1. При отправке с телефона обычному удалённому контакту свой узел видит текст до шифрования между узлами. Первый ключ TOFU нужно независимо сверить по отпечатку.
- Закрытая среда: данные владельца запечатаны паролем; служебные данные, нужные при блокировке, защищены ключом устройства. Сид-фраза используется для восстановления; предусмотрено аварийное удаление с [оговорёнными пределами](docs/PRIVACY.md).
- Роли: администратор (отдельный пароль, сеанс 15 минут), пользователь, гость; приглашения с PIN по цепочке доверия.
- Подписанный список входных узлов для телефонов и новых узлов; заявки новых узлов (только данные подключения).
- Выход в интернет через другой узел (HTTP/SOCKS5): быстрый режим и многопереходная маршрутизация с послойным шифрованием. Полная анонимность не заявляется.
- Подписанные выпуски и установщик с проверкой подписи и защитой от отката.
- Русский и английский языки в консоли, оболочке и приложении.

Ограничения описаны в [английском README](README.md#honest-status) и [карте шифрования](docs/CRYPTO_MAP.md): независимого аудита не было, защита зависит от пути передачи, метаданные не скрываются. Подтверждённые находки R16 исправлены в экспериментальной ветке и проверены автотестами; обновление пакетов на чистой системе ещё не испытано. Подробности — в [`docs/R16_REMEDIATION.md`](docs/R16_REMEDIATION.md). План: [`docs/ROADMAP.md`](docs/ROADMAP.md).
