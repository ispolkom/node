# YANDI

**Одноранговая сеть для свободного общения.** Чаты, файлы, группы и звонки через ваш собственный узел, со сквозным шифрованием между устройствами. Без центрального сервера и без учётных записей.

## Установка узла из консоли

```bash
sudo apt install ./yandi-node_0.2.0-g829_amd64.deb
yandi setup                       # язык, пароль, сид-фраза (12/24 слова), закрытая среда — от обычного пользователя
yandi admin pairing owner --host ВАШ_ВНЕШНИЙ_АДРЕС     # код и QR для телефона
```

**Запишите сид-фразу на бумагу:** она показывается один раз. Служба systemd, порты (`8444/tcp`, `9000/udp`, `10000/udp`) и сетевые буферы: пошаговая инструкция на страницах [Debian](https://yandi.su/ru/network/downloads/debian/) и [Ubuntu](https://yandi.su/ru/network/downloads/ubuntu/) и в [`DEPLOYMENT.md`](DEPLOYMENT.md). Удаление: `apt remove yandi-node` оставляет данные, `apt purge yandi-node` стирает их без следа.

## Что есть

- Чаты, файлы, группы, звонки через свой узел; сквозное шифрование между телефонами.
- Закрытая среда: личные данные запечатаны вашим паролем, одна сид-фраза восстанавливает узел и среду; аварийное стирание.
- Роли: администратор (отдельный пароль, сеанс 15 минут), пользователь, гость; приглашения с PIN по цепочке доверия.
- Подписанный список входных узлов для телефонов и новых узлов; заявки новых узлов (только данные подключения).
- Выход в интернет через другой узел (SOCKS5): быстрый и «анонимный» режимы, цепочки через несколько узлов.
- Подписанные выпуски и установщик с проверкой подписи и защитой от отката.
- Русский и английский языки в консоли, оболочке и приложении.

Что ещё не готово, сказано прямо в [английском README](README.md#honest-status): нет независимого аудита, нет асинхронного E2E между узлами, метаданные не скрываются. План: [`docs/ROADMAP.md`](docs/ROADMAP.md).
